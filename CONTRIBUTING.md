# Contributing

## Requirements

- Node.js >= 24
- npm >= 10

## Getting Started

```bash
git clone https://github.com/7893/nextui-showcase.git
cd nextui-showcase
npm install
npm run dev
```

## Guidelines

- Commit messages must be in English, max 8 words
- Run `npm run lint` and `npm run build` before submitting a PR
- All PRs target the `main` branch
